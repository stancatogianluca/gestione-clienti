GESTIONE CLIENTI v1.0 - PWA iPhone

Pubblicazione:
1. Crea un NUOVO repository GitHub chiamato gestione-clienti (non usare Dieta FC o Presenze ISS).
2. Carica nella radice del repository tutti i file di questa cartella.
3. In Settings > Pages, scegli Deploy from a branch, main, /(root), Save.
4. Apri https://TUO-USERNAME.github.io/gestione-clienti/ con Safari su iPhone.
5. Condividi > Aggiungi alla schermata Home.
6. Apri l'app e imposta una password principale di almeno 10 caratteri.

L'archivio cifrato resta sul dispositivo. Nessuna sincronizzazione tra dispositivi.
Non perdere la password principale: senza di essa i dati non sono recuperabili.
Esporta backup cifrati periodicamente e conservali in un posto sicuro.
GitHub ospita solo il codice, non i dati dei clienti.
L'app non invia notifiche push: mostra le scadenze quando viene aperta.
